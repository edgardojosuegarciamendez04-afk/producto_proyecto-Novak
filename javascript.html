JavaScript (JS Vanilla)

JavaScript es el lenguaje de programación que otorga interactividad y dinámica a los sitios web en el navegador del usuario.

Diferencias fundamentales

  • HTML: Estructura del sitio web.
  • CSS: Diseño y aspecto visual.
  • JavaScript: Comportamiento e interactividad.

Conceptos Clave

Variables: Contenedores de datos (ej. let precio = 75;).

Funciones: Bloques de código reutilizables.

Eventos: Acciones del usuario como click o hover.

Ejemplo de Código Explicado

// Selecciona el botón de compra
const btnComprar = document.getElementById("btn-comprar");

// Agrega un evento al hacer clic
btnComprar.addEventListener("click", function() {
    alert("¡Prenda NØVAK agregada al carrito!");
});
