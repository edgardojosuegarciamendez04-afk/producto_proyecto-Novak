Web Hosting y Dominios

Hosting: Servidor que guarda los archivos web. Vercel despliega proyectos estáticos directamente desde GitHub.

Dominio / Domain: La dirección de tu sitio (ej. novakwear.com).

DNS: Sistema que convierte el nombre del dominio en una dirección IP del servidor.
