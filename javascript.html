JavaScript (JS Vanilla)

Es un lenguaje de programación interpretado que añade interactividad a las páginas web.

Diferencias clave:

  • HTML: Estructura el contenido.
  • CSS: Agrega estilos visuales.
  • JavaScript: Maneja la lógica y las acciones del usuario.

Ejemplo Práctico:

const boton = document.getElementById("btn-comprar");
boton.addEventListener("click", function() {
    alert("¡Prenda NØVAK agregada al carrito!");
});
