JavaScript (JS Vanilla)

JavaScript es un lenguaje de programación interpretado e interactivo que impulsa la lógica en el navegador.

Diferencias Clave

  • HTML: Define el contenido y la estructura básica del documento.
  • CSS: Aplica colores, tipografías y el diseño estético de la marca.
  • JavaScript: Procesa las respuestas a eventos, cálculos y lógica interactiva.

Ejemplo de Evento Clic en Pantalla

Este código escucha el evento 'click' del usuario y responde con una alerta interactiva sin recargar la página:

// Selecciona el botón de compra
const btnComprar = document.getElementById("btn-comprar");

// Registra la interacción del cliente
btnComprar.addEventListener("click", function() {
    alert("¡Prenda NØVAK agregada al carrito con éxito!");
});
