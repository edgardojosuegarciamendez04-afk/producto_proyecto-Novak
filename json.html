JSON (JavaScript Object Notation)

Formato de texto ligero utilizado para transferir datos de productos o inventario entre el cliente y el servidor.

Ejemplo de Estructura JSON:

{
  "producto": "Chaqueta NØVAK",
  "precio": 85.00,
  "disponible": true,
  "tallas": ["S", "M", "L"]
}
